# ClassTell

适用于希沃大屏的一个**叫人自动化命令软件**。

> **商用请联系邮箱：** [qe_ge@outlook.com](mailto:qe_ge@outlook.com)

**ClassTell 使用说明**
**版本：** `v1.0.0a_1`（.NET Framework 4.8 / WinForms）

---

## 一、这是什么

ClassTell 把“邮件”当作远程指令使用：

* 使用 OAuth2（Modern Auth）登录 Outlook / Microsoft 365 邮箱；
* Microsoft Graph：轮询收件箱未读邮件
* 邮件标题写命令字，正文第一行作为标题，后续内容作为正文；
* 收到“呼叫”类指令后，会弹出系统通知（通知区域气泡），并将内容显示在消息界面。


---

## 二、运行环境

* Windows 7 SP1 / 8.1 / 10 / 11

  * 建议使用 Windows 10 及以上版本，通知区域支持更加完整；
* .NET Framework 4.8 运行时

  * Windows 10 1809 及以上系统通常自带；
* 需要能够访问：

  * `outlook.office365.com:993`
  * `login.microsoftonline.com:443`

## 三、安装与启动

### 安装

1. 将发布目录（`bin\Release\net48` 或 `bin\Debug\net48`）整体复制到任意位置；
2. 双击 `ClassTell.exe`；
3. 首次启动会自动进入 **“关于 → 邮箱登录”**，并打开浏览器要求登录；
4. 程序为单实例运行，重复启动时会提示“已经在运行中”。

### 启动参数

以下参数为可选参数，主要用于诊断：

```text
ClassTell.exe --no-login
```

不自动弹出登录界面，可用于离线查看界面。

```text
ClassTell.exe --demo
```

注入 5 条示例消息，并模拟一次 `C / call` 通知，便于预览界面及动效。

## 四、邮箱登录（OAuth2 / Modern Auth）

### 4.1 服务器配置

| 项目   | 配置                      |
| ---- | ----------------------- |
| 服务器  | `outlook.office365.com` |
| 端口   | `993`                   |
| 加密   | SSL/TLS                 |
| 认证方式 | OAuth2（Modern Auth）     |

### 4.2 登录方式

#### 方式一：使用浏览器登录

调用系统默认浏览器完成微软账号登录。

支持：

* 个人 Outlook.com 账号；
* 工作/学校账号；
* MFA（多因素认证）；
* 条件访问等微软账号安全策略。

MFA、条件访问等功能由微软登录页面自行处理。

#### 方式二：使用设备代码登录

适用于：

* 无浏览器环境；
* 远程桌面环境；
* 其他不方便直接打开浏览器的场景。

程序会给出类似以下格式的设备代码：

```text
XXXX-XXXX
```

然后在任意设备打开：

```text
https://microsoft.com/devicelogin
```

输入设备代码完成登录。

### 4.3 登录令牌缓存

登录成功后，令牌会缓存到本机：

```text
%APPDATA%\ClassTell\msal_token_cache.bin
```

下次启动时会自动尝试静默刷新，无需重复登录。

点击 **“退出登录”** 后，会清空本地令牌缓存。

### 4.4 高级设置

高级设置提供以下三个选项：

#### 客户端 ID

公共客户端 ID。

默认使用 Thunderbird 的公共客户端 ID，可直接登录。

建议将其替换为自己在 Entra ID 中注册的应用。

#### 租户

支持以下配置：

```text
common
```

个人账号 + 组织账号。

```text
consumers
```

仅个人账号。

```text
organizations
```

仅组织账号。

也可以填写自己的租户域名或租户 ID。

#### 权限范围

默认：

```text
https://outlook.office.com/IMAP.AccessAsUser.All
```

如果需要发信功能，可以额外添加：

```text
https://outlook.office.com/SMTP.Send
```

多个权限之间使用空格分隔。

### 4.5 自己注册应用

**推荐使用自己注册的应用。**

操作步骤：

1. 打开 **Entra 管理中心**；
2. 进入 **应用注册**；
3. 点击 **新注册**；
4. 账户类型选择：

   > 任何组织目录中的账户和个人 Microsoft 账户
5. 平台选择：

   > 移动和桌面应用程序
6. 重定向 URI 填写：

   ```text
   http://localhost
   ```
7. 在“身份验证”中打开：

   > 允许公共客户端流
8. 在“API 权限”中添加：

   ```text
   Office 365 Exchange Online
   └── IMAP.AccessAsUser.All
   ```

   如果需要发信功能，可额外添加：

   ```text
   SMTP.Send
   ```
9. 将 **“应用程序（客户端）ID”** 填写到 ClassTell 的高级设置中。

## 五、邮件格式约定

> **注意：必须严格按照以下格式发送邮件。**

本软件不使用任何自有弹窗。

所有提醒均通过：

* 系统通知区域；
* 系统对话框；

进行呈现。

### 5.1 邮件格式

```text
标题：AAAA
正文第一行：BBBB
第一行之后：CCCC
```

其中：

| 部分     | 含义   |
| ------ | ---- |
| `AAAA` | 命令字  |
| `BBBB` | 消息标题 |
| `CCCC` | 消息正文 |

正文会保留原有换行，并完整显示。

### 5.2 命令字

| 命令字          | 功能                  |
| ------------ | ------------------- |
| `C` / `call` | 呼叫：弹出系统通知，同时显示在消息界面 |
| `T` / `tell` | 提示：只在消息界面显示，不弹出通知   |
| 其他内容         | 忽略该邮件，并写入日志         |

### 5.3 通知内容格式

对于 `C / call` 命令：

```text
标题：BBBB
内容：CCCC
来源于：发件人邮箱地址
```

正文会保留换行。

如果正文过长，会自动截断并添加 `…`。

### 5.4 命令解析规则

以下规则均支持：

* 命令字大小写不敏感；
* 命令字前后空格会被自动忽略；
* `[C]`、`CALL` 等形式也可以识别；
* 如果正文第一行写成：

  ```text
  标题：xxx
  ```

  程序会自动去掉 `标题：` 前缀。

# 七、动效、配色与屏幕适配

## 7.1 配色

### 深色模式

主要背景：

```text
#121316
#1B1D21
```

### 浅色模式

## 7.2 动效

采用 Material 风格标准缓动，例如：

```text
cubic-bezier(0.4,0,0.2,1)
```

支持：

* 按钮水波纹；

## 7.3 屏幕适配

采用**响应式布局**，不会针对某一个固定分辨率写死。

### 字号计算

字号以磅（pt）定义，并按照系统 DPI 进行像素渲染：

```text
像素 = 磅 × 系统 DPI ÷ 72
```

例如：

```text
100% 缩放：
10pt ≈ 13px
```

在 `200%` 缩放下，物理像素会翻倍，但逻辑尺寸保持不变。

因此不会出现：

* 高缩放屏幕字体被重复放大；
* 高缩放下界面拥挤；
* 低分辨率下字体过小。

### 启动时布局计算

启动时根据：

```text
系统 DPI
+
可用显示区域
```

计算实际布局。

其中：

```text
逻辑区域 = 物理像素 ÷ 系统缩放
```

### 紧凑系数

根据逻辑显示区域自动调整：

| 逻辑区域            |   紧凑系数 |
| --------------- | -----: |
| `< 1366 × 800`  | `0.84` |
| `< 1680 × 1000` | `0.92` |
| 其他              | `1.00` |

紧凑系数只用于收紧：

* 间距；
* 圆角；
* 导航栏宽度。

**不会缩小字体。**

### 首次运行字号

首次运行时，根据逻辑屏幕高度在 `9 ~ 10.5pt` 之间自动选择推荐字号。

默认字号：

```text
10pt
```

用户可以在：

> 关于 → 界面设置

中调整。

可调范围：

```text
8 ~ 16pt
```

并自动保存。

### 自适应布局

所有以下尺寸均根据字体度量自动计算：

* 行高；
* 页头；
* 页脚；
* 卡片内边距；
* 按钮高度；
* 翻页控件。

改变字号后：

* 不会重叠；
* 不会截断；
* 不会错位。

窗口尺寸也会根据工作区自动收缩。

支持：

* 高分辨率；
* 低分辨率；
* 高 DPI；
* 低 DPI；
* 高缩放；
* 小尺寸屏幕。

### 字体

统一使用：

```text
微软雅黑（Microsoft YaHei）
```

# 九、常见问题

## 1. 提示“登录状态已过期/需要重新登录”

进入：

> 关于 → 邮箱登录

重新登录即可。

## 2. 登录报权限 / 同意错误

确认邮箱属于：

* Microsoft 365；
* Outlook.com。

如果组织要求管理员同意：

* 改用自己注册的应用；
* 或让管理员为默认客户端 ID 授权。

## 3. 一直显示“正在连接”

检查：

* 网络是否正常；
* 代理是否允许 `993` 端口；
* TLS 是否被拦截；
* 公司网络是否存在 IMAP 拦截。

具体错误信息会记录在：

```text
%APPDATA%\ClassTell\log.txt
```

## 4. 收不到新邮件

检查：

1. 邮箱是否超过存储配额；
2. 账号是否启用了 IMAP；
3. 网络是否正常。

程序默认使用 `IMAP IDLE` 进行实时推送。

如果服务器不支持 IDLE，会自动退化为定时轮询。

默认轮询间隔：

```text
20 秒
```

可以通过：

```text
PollSeconds
```

进行修改。

## 5. 同一个未读邮件每次启动都会显示

默认：

```text
MarkAsSeen=false
```

因此程序不会主动修改邮箱中的邮件已读状态。

启动时默认会回溯最近 `10` 封未读邮件。

可以通过：

```text
RecentScanCount
```

进行调整。

有效范围：

```text
0 ~ 200
```

其中 `0` 表示只接收程序启动后的新邮件。

## 6. 通知没有出现

检查 Windows：

> 设置 → 系统 → 通知

确认允许 ClassTell 发送通知。

同时检查：

* 聚焦助手；
* 勿扰模式；
* Windows 通知权限。

此类系统开关由 Windows 自身控制，ClassTell 不会额外创建自有弹窗。

* 反复切换深浅主题；
* 无深色残留；
* 界面渲染；
* 田字格消息列表；
* 页内详情视图；
* 系统通知；
* 导航；
* 字号滑块；
* 程序集内不存在自有窗体；
* 除主窗口外无其他窗体类型；
* 发送通知不会创建窗口。
